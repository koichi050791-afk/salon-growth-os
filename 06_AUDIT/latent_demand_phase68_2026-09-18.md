# Phase68｜未顕在需要マップ v0.1

作成日: 2026-09-18  
対象: 三田エリアの顧客集客 / SARAJU三田店求人  
目的: 大手媒体が強い「検索・比較・予約/応募」の手前にある未顕在の迷いを発見し、反応を検証し、相談・来店・見学につながる再利用可能な知見へ変える。

## 1. 基本戦略

同じ土俵で大手と戦わない。

狙うのは、まだ「美容室を探す」「求人を探す」まで顕在化していない層。

### 顧客集客
- Aしたい。でもBは嫌 / 不安。
- 施術名が決まっていない。
- 変えたいが失敗したくない。
- 自分に何が必要か分からない。

### 求人
- 美容師に戻りたい。でもブランクが怖い。
- 美容師は続けたい。でも以前の働き方には戻りたくない。
- 子育てと両立したいが、どんな条件なら働けるか分からない。
- 三田で生活に近い場所で働きたいが、まだ求人検索まではしていない。

## 2. 媒体の役割

- Threads: 未顕在の迷いを発見・検証する。
- 顧客向けnote: 反応した迷いを深掘りし、検索・AI検索で再利用できる資産にする。
- 公式Web / 髪の相談: 「自分の場合」を判断する受け皿。
- 求人Instagram: 店・人・働き方の雰囲気を確認する受け皿。
- 求人サイト: 復帰・転職の判断材料。応募前に条件を確認する場所。
- LINE / 相談: 個別条件・個別不安の確認。
- 予約 / 見学 / 応募: 最終行動。

## 4. 証拠レベル

需要テーマは以下の4段階で扱う。

### L0 仮説
こちらが想定しただけ。反応・一次情報なし。

### L1 初期シグナル
1投稿の反応、1件の相談、1件の実在事例などがある。
まだ勝ち筋認定しない。

### L2 反復確認
異なる投稿 / 記事 / 相談で同じ迷いが複数回確認される。
媒体をまたいでも同じ傾向が見える。

### L3 行動確認
相談、LINE、予約、見学、応募など、次の行動が確認される。

### L4 成果確認
顧客なら来店・再来。
求人なら応募・採用・定着。
ここまで到達して初めて「勝ち筋候補」とする。

## 5. 現在の優先順位

### 顧客集客: 次に検証する3テーマ
1. 軽くしたい。でもスカスカは嫌
2. 白髪は染めたい。でも暗くしたくない
3. 変えたい。でも失敗したくない
   - 下位検証: 短くしたいが怖い / レイヤーで広がるのが怖い

縮毛矯正は除外しないが、現時点では「縮毛矯正」という施術語より、
- 広がる
- うねる
- 量なのかクセなのか分からない
の生活言語で再検証する。

### 求人: 次に検証する3テーマ
1. 美容師に戻りたい。でもブランクが怖い
2. 美容師は好き。でも以前と同じ働き方には戻りたくない
3. 三田で生活に近い場所で働きたい

子育て / 時短 / 土日 / 急病は重要だが、会社側の実条件が確定するまで「できます」と訴求しない。

## 6. Threads → 資産化の昇格ルール

Threads投稿が伸びたから即note化しない。

以下のどれかを満たした場合に「深掘り候補」へ上げる。

1. 同一テーマで複数投稿に反応がある
2. コメント / 返信に具体的な迷いが出る
3. noteや既存記事でも同じテーマの閲覧実績がある
4. 実際の相談・来店理由として同じ迷いが確認される
5. 求人ではLINE相談・見学・質問として同じ障壁が確認される

### 顧客向け
- 既存noteがある → まず追記 / タイトル改善 / 内部リンク
- 既存noteで答えきれない → 新記事
- 個別性が高い → 公式Web事例 / 髪の相談へ
- 施術事例として判断価値がある → 匿名Caseとして再利用

### 求人向け
- 反応が出たが条件未確定 → Threadsで観察継続
- 会社側で事実確認できた → 求人サイトFAQ / Instagram固定投稿へ反映
- 個別相談が発生 → 匿名で質問テーマだけ記録
- 見学理由として複数回出る → 採用サイトの中核訴求へ昇格

## 7. 見ない数字 / 見る数字

### 補助指標
- Threads表示数
- いいね
- note PV
- フォロワー

### 重要指標
- 返信 / コメントに出た具体的な迷い
- プロフィール・相談導線への移動
- note → 公式Web / 髪の相談 / LINE
- 求人サイト → LINE / 見学
- 実来店時の「何を見た / 何が決め手」
- 見学時の「何が不安だった / 何で知った」

最上位は、顧客なら「相談→来店」、求人なら「相談→見学→採用→定着」。

## 9. 運用ループ

### 日常
現場 / Threads / note / 地域観察で具体的な迷いが確認されたら、既存テーマの証拠レベルだけ更新する。
新しい管理画面・入力フォームは作らない。

### 週次
1. 強い反応が出たテーマを最大3件確認
2. 既存note / Web / 求人サイトに答えがあるか確認
3. 既存資産改善か、新規検証かを決める
4. 相談・来店・見学へ進んだテーマだけ証拠レベルを上げる

### 月次
- どの迷いがL2以上になったか
- どの迷いが行動につながったか
- どのテーマは反応しなかったか
- 何をやめるか
を確認する。

## 10. 勝ち筋認定条件

「勝ち筋」と呼べるのは、原則として以下を満たしたテーマ。

- 同じ迷いが複数回確認される
- Threadsだけでなく、note / 相談 / 来店 / 見学など別の証拠がある
- 池田 / SARAJU側が実際に解決可能
- 無理な値引き、長時間労働、過剰な媒体追加を必要としない
- 再現可能な言葉・導線・判断として残せる

単発のバズは勝ち筋に含めない。

## 11. 2028年へ残すもの

残すのは「三田で伸びた投稿一覧」ではない。

残すのは、
- 地域の未顕在需要をどう見つけたか
- どの迷いに反応があったか
- どの言葉なら会話が始まったか
- どの深掘りが相談につながったか
- どこで予約 / 見学 / 応募へ進んだか
- 何が反応しなかったか
という方法論。

三田 = 検証・形式知化  
尼崎 = 移植・再現・事業化

## 12. 現在地

このPhaseの直近ゴールは、集客・求人それぞれでL2以上のテーマを3件以内に絞ること。

発信量を増やすフェーズではない。
「大手が拾う前の迷い」のうち、池田 / SARAJUが本当に解決でき、相談・来店・見学につながるものを選別するフェーズとする。
