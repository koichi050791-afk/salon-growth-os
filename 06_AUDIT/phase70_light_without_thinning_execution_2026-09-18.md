## 2. Threads 3本シリーズ

### 投稿1｜欲しいのは「量を減らすこと」ではないかもしれない

本文:
髪は軽くしたい。
でも、毛先がスカスカになるのは嫌。
この2つは、両立できます。

コメント①:
「軽くする＝全体をたくさんすく」ではありません。
見た目を軽くしたいのか、乾かしやすくしたいのか、動きが欲しいのかで考え方は変わります。

コメント②:
僕は先に「どこを減らすか」より「どこを残すか」を見ます。
毛先がすでに軽いなら、さらに減らさないこともあります。

狙い:
入口ワードの再現確認。

### 投稿2｜重い場所と、減らしていい場所は同じではない

本文:
髪が重く感じる。
だから量を減らす。
この順番で考えないことがあります。

コメント①:
後ろだけ髪がたまっていることもあれば、
毛先はすでに軽くなっていることもあります。

コメント②:
同じ一つの髪型でも、
減らす場所と残す場所を分ける。
その方が「軽いけど薄く見えない」に近づくことがあります。

狙い:
「重さ≠毛量」の理解を作る。

### 投稿3｜レイヤーを入れるか、量を減らすかの二択ではない

本文:
レイヤーは入れたい。
でも広がるのは嫌。
そんな時も、全部を軽くする必要はありません。

コメント①:
レイヤーを入れる場所。
入れない場所。
毛量を減らす場所。
残す場所。
分けて考えます。

コメント②:
「軽くしたい。でもスカスカは嫌」
「動きは欲しい。でも広がりたくない」
このままの言葉で相談してもらって大丈夫です。

狙い:
レイヤー需要を同一テーマへ統合。

## 6. L3判定

次のどれかが確認できたらL3へ上げる。

- このテーマを見て髪の相談へ進んだ
- LINE / 予約時に「軽くしたい・スカスカは嫌」が確認された
- 来店時にThreads / note / Webのいずれかを見たと本人が述べた
- note / Webを見たことが来店判断に関与した

単なる表示数・いいねではL3にしない。

## 7. 記録する最小事実

個人情報は残さない。

- 入口: Threads / note / Web / その他
- 迷い: 軽くしたい / スカスカ不安
- 次行動: 相談 / 予約 / 来店
- 決め手: 本人が明示した場合だけ
- 結果: 来店確認まで

## 8. 停止条件

以下が続く場合は一点突破の表現を見直す。

- 3本以上再検証して具体的反応が出ない
- 相談行動へ全く進まない
- 実来店理由と結びつかない
- 顧客の言葉として別表現の方が繰り返し出る
