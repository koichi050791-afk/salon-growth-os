# Phase69｜ニッチ需要の占有設計 v0.1

作成日: 2026-09-18  
対象: 三田の顧客集客 / SARAJU三田店求人  
目的: Phase68で発見・検証する未顕在需要を、単発投稿ではなく「入口→理解→判断→相談」の一貫した受け皿へ変える。

## 1. 基本方針

大手と同じ土俵で戦わない。

大手が強いのは、すでに検索・比較・予約・応募を始めた顕在層。
こちらは、その前にある「まだ何を探せばいいか分からない迷い」を取る。

したがって、媒体の役割を固定する。

- Threads = 迷いの発見・検証
- note = 迷いの深掘り・検索資産化
- 公式Web = 自分の場合を判断する
- 髪の相談 = 個別整理
- Instagram = 雰囲気・人・実例の確認
- 求人サイト = 働き方の判断
- LINE = 個別条件の確認
- 予約 / 見学 = 最終行動

## 2. 顧客集客の占有テーマ

### A｜軽くしたい。でもスカスカは嫌

現在地: L2

#### 入口
Threads:
- 軽くしたい。でも毛先がスカスカになるのは嫌
- 広がるからといって、全体の量を減らせばいいとは限らない
- レイヤーを入れたい。でも広がるのが怖い

#### 深掘り
既存note代表:
- na96e09757a47

既存72記事のうち同系統22記事。
新規記事量産はしない。

#### 判断
公式Web側では、
- どこを軽くするか
- どこを残すか
- レイヤーと毛量調整の違い
- 広がりとの関係
を「施術メニュー」ではなく「判断軸」として見せる。

#### 相談
「軽くしたいけど、減らしすぎたくない」とそのまま相談できる状態にする。

#### 占有したい認識
「軽くしたいけど失敗したくない時に相談できる美容師」

## 3. 顧客側の情報構造

### レベル1｜Threads
一投稿 = 一つの迷い。
複数テーマを混ぜない。

### レベル2｜note
Threadsで反復確認された迷いを深掘り。
既存記事がある場合は新規作成より改善を優先。

### レベル3｜公式Web
記事を読む場所ではなく、
「自分の場合はどれに近いか」
を判断する場所。

### レベル4｜髪の相談
個別の迷いを整理する。
メニュー選択を先に要求しない。

### レベル5｜予約
最終行動。
予約媒体自体を競争優位にしない。

## 4. 求人の占有テーマ

### R1｜美容師に戻りたい。でもブランクが怖い

現在地: L1強

#### 入口
採用Threads:
- 美容師免許はある
- 何年もハサミを持っていない
- 今さら戻れるか不安

#### 理解
求人Instagram:
- 店の雰囲気
- スタッフ
- マンツーマンの働き方
- 一日のイメージ

#### 判断
求人サイト:
- 応募前に質問できる
- 見学できる
- ブランク年数や技術状態は個別確認

#### 相談
LINE:
「ブランクがあります」とそのまま相談できる。

#### 禁止
会社確認前に、
- ブランクOK
- 研修あり
- 復帰支援あり
と断定しない。

#### 占有したい認識
「美容師復帰を決める前に相談できる三田のサロン」

## 5. 求人側の情報構造

Threads
→ 「自分のことかも」

Instagram
→ 「どんな店 / 人だろう」

求人サイト
→ 「自分の条件と合うか」

LINE
→ 「自分の場合はどうか」

見学
→ 「実際に働くイメージが持てるか」

応募
→ 最後に判断

応募を最初のCTAにしない。

## 6. 昇格式

### L0
Threadsで仮説検証のみ。
Webやnoteを大きく変えない。

### L1
既存受け皿があるか確認。
不足していても大規模実装しない。

### L2
既存note / Web / 求人サイトの中核テーマへ昇格可能。
- 見出し
- FAQ
- 内部リンク
- 固定投稿
のいずれかを強化する。

### L3
相談・LINE・予約・見学が発生。
専用導線の優先度を上げる。

### L4
来店 / 再来 / 採用 / 定着。
「勝ち筋候補」として三田モデルに正式採用する。

## 7. 増やさないルール

反応が出たからといって、
- 新しいSNS
- 新しいブログ
- 新しいLP
- 新しいLINE
- 新しい管理ツール
を作らない。

まず既存の、
Threads / note / 公式Web / 髪の相談 / Instagram / 求人サイト / LINE
の中で解決する。

## 8. 計測

### 顧客
Threads反応
→ note閲覧
→ 公式Web
→ 髪の相談
→ LINE / 予約
→ 来店

### 求人
採用Threads反応
→ Instagram
→ 求人サイト
→ LINE
→ 見学
→ 応募
→ 採用
→ 定着

表示数・PVは補助指標。

最重要:
- 何に迷っていたか
- 何を見て相談したか
- 何が決め手だったか

## 10. Phase69終了条件

以下が揃った時点でPhase70へ進む。

- 顧客側: L2以上が2〜3テーマに収束
- 求人側: L2以上が1〜3テーマに収束
- 少なくとも1テーマでL3の行動確認
- そのテーマの入口→理解→判断→相談導線が途切れていない
- 新規媒体を増やさず既存資産内で成立

## 11. 2028年への移植

三田で残すのは媒体ではなく、

未顕在の迷いを発見
→ 言葉を検証
→ 深掘り
→ 判断材料化
→ 相談
→ 行動
→ 結果を再利用

という地域ニッチ需要の占有手順。

尼崎では、三田のテーマそのものをコピーせず、
この手順だけを移植して現地の迷いを再発見する。
