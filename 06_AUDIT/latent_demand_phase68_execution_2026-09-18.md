## 5. 判定ルール

投稿ごとに固定の「合格表示数」は設定しない。
アカウント規模・配信状況で変わるため。

### 継続
- 返信/コメントで具体的な悩みが出る
- 同テーマの過去投稿と同方向の反応が出る
- note / Web / LINE / 来店理由と重なる

### 深掘りへ昇格
- L2: 同じ迷いが別投稿または別媒体でも反復
- L3: 相談 / LINE / 予約 / 見学に進む
- L4: 来店 / 再来 / 採用 / 定着まで進む

### 停止 / 言い換え
- 表示は出るが具体的反応がない状態が続く
- 施術名・制度名だけでは反応せず、生活言語へ変える余地がある
- 会社側が実際に解決できない求人障壁

## 6. note / Webへの振り分け

### 軽くしたい × スカスカ
既存noteの改善を優先。記事量産しない。

### 白髪 × 暗くしたくない
既存代表記事を中心に、Threads反復後にタイトル・冒頭・内部リンクを再評価。

### 短くしたい × 怖い
既存代表記事が少ないため、反応がL2へ上がれば既存記事強化を最優先。
実在Caseが増えた場合のみ補助記事を検討。

### 求人3テーマ
noteを新設しない。
Threads → Instagram → 求人サイト → LINE/見学の既存導線で検証する。
条件が確定し、同じ質問が繰り返された項目だけ求人サイトFAQへ追加する。

## 7. 最小記録

新しいフォームや台帳を増やさない。
週次レビュー時に各テーマへ以下だけ追記する。

- 最新の証拠レベル L0〜L4
- 証拠になった投稿/記事/相談の事実
- 次の処置: 継続 / 深掘り / 停止
- 解決可能性: 確認済み / 未確認 / 不可

個人名・連絡先・予約情報は記録しない。
