# Threads / note Operating System

## 位置づけ

このOSは「Threadsを伸ばす仕組み」ではない。

現在収益エンジン:
美容師として顧客へ価値を提供する。

知的資産エンジン:
現場で生まれたCase / Decision / 実測 / AI活用をKnowledge化し再利用する。

Threadsとnoteは、この2つを接続する媒体として扱う。

## 役割

### Research
実測を集め、事実・観測・仮説・未確認に分ける。

### Planning
次に検証する1点を決める。

### Writing
企画を文章に変える。事実は増やさない。

### Review
事実・ブランド・計測・導線を監査する。

### Human Gate
池田航一。
顧客心理の解釈、ブランド判断、重要な経営判断、Knowledge正式採用、最終意思決定を行う。

## ツール分担

Human:
一次情報・現場・最終判断。

ChatGPT:
意味づけ・仮説・戦略・問題設定・優先順位。

Work / connector:
Threads、GA4、Web、note等の実データ確認・操作。

Codex:
整理・計算・比較・検査・反復・仕組み化。

## Knowledge昇格条件

単発バズはKnowledgeにしない。

候補:
- 複数回再現した
- 違う投稿でも同じ傾向が出た
- 予約・購入など下流成果につながった
- 次の仕事で再利用された

正式採用はHuman Gate。

## 失敗時

API投稿が「Published」と返っても、可能ならread-backまたは公開画面で確認する。
返信APIが resource not found / Fatal の場合、成功扱いにしない。
同じ投稿を無限再試行しない。
重複投稿を最優先で避ける。

## 最終問い

すべての重要な活動で確認する。

「これは2028年以降の池田航一に何を残すのか？」

残らないなら減らす。
残るなら蓄積する。
再利用できるならKnowledge化する。
繰り返すなら仕組みにする。
AIへ渡せるなら渡す。
