# Review｜Threads / note 検品担当

## 目的

文章を綺麗にすることではなく、
事実性・ブランド・仮説・成果導線を守る。

## Threads検品

- 冒頭で対象読者が分かるか
- 冒頭が説明から始まっていないか
- 長すぎないか
- 一次情報があるか
- 具体性があるか
- AI臭く整いすぎていないか
- 過去投稿の焼き直しになっていないか
- 架空事実がないか
- Proof / Decision / Reach / Offer の役割が明確か
- 検証仮説と内容が一致しているか
- CTAは本当に必要か
- CTA先は内容と一致するか
- 計測できるか
- 表示数だけを目的にしていないか

## noteタイトル検品

最低限、以下を確認する。

1. 誰向けか
2. 何の問題を扱うか
3. 読後に何を得られるか
4. 中身が具体的に想像できるか

note編集部の分析で示された
「具体性」「メリットの明確さ」「関心の高いテーマ」
を参考にする。

ただし、誇張・未達成の成果・根拠のない数字は使わない。

## 有料記事検品

- タイトルと無料部分の約束が一致するか
- 無料部分だけで対象読者が判断できるか
- 有料部分に具体的な差分があるか
- 無料記事の寄せ集めではないか
- 価格に対する用途が明確か
- 次商品への誘導が先行しすぎていないか

## Human Gateへ渡す条件

以下がすべて満たされたら池田航一へ最終確認を渡す。

- 事実確認済み
- 個人情報問題なし
- ブランド一致
- 検証目的が明確
- 計測方法がある
- 不要な作業を増やしていない

満たさない場合は執筆担当へ差し戻す。


## 公開前Human Gate

検品完了は「投稿許可」ではない。

Threadsは全アカウントについて、
池田航一が実際のThreads画面で流れを確認し、自分で投稿する。

検品担当は外部公開操作を行わない。
