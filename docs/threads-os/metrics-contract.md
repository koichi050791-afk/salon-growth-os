# Metrics Contract｜Threads / note

## 目的

媒体ごとの数字を混ぜず、同じ言葉で同じ意味を測る。

## 集客ファネル

### Threads表示
Windsor.ai `post_views`。
投稿が表示・再生された回数。ユニーク人数ではない。

### プロフィール訪問
Windsor.ai `profile_views`。
日次指標。個別投稿へ完全帰属できない場合は推測しない。

### Threads→note
公式Webの計測リダイレクトで `threads_to_note` を送信。
テーマ単位で測る。

対象ルート:
- /go/threads/menu-uncertain/
- /go/threads/hair-volume/
- /go/threads/change-without-length/

### note→予約
既存リダイレクトで `note_to_booking`。
予約画面へ進んだイベントであり、予約完了ではない。

### 予約クリック
`reservation_click` または文脈別の予約クリックイベント。
予約完了と区別する。

### 実予約
予約システムで予約成立が確認できたもの。
GA4クリックから自動的に同一人物だと断定しない。

### 実来店
実際に来店した一次情報。
最重要成果の一つ。

### 技術売上
実来店に紐づく技術売上。
SNS表示数と直接の因果を単発で断定しない。

## 収益化ファネル

### Threads無料接触
表示 / プロフィール / リンククリック。

### note閲覧
note側で確認できるPV等。

### 購入導線
無料部分から有料部分・購入画面へ進んだことが取れる場合だけ記録。
取得できない指標は「不明」。

### 購入
noteの販売実績で確認。
公開ページの価格表示は購入数ではない。

## 判定ルール

- 表示が高い = Reach成功候補
- プロフィール率が高い = 認識形成候補
- リンク率が高い = CTA/テーマ適合候補
- note→予約が出る = 成果転換候補
- 実来店が出る = 強いEvidence候補
- 購入が出る = 商品価値仮説のEvidence候補

いずれも単発ではKnowledge確定しない。

## 欠損

取れない数字は0にしない。
「不明」「未計測」「取得不可」を区別する。
