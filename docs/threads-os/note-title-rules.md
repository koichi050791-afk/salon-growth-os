# note Title Rules｜有料noteタイトル設計

## 参照

note編集部が「特に購入されている有料記事500件」を分析した公式記事を参考にする。

Source:
https://note.com/notemag/n/n367ec637ae54

## 参考にする原則

購入されている記事タイトルに見られた主な特徴:
- 内容が具体的
- 読者が得られるメリットが明確
- 関心の高いテーマが含まれている

note側ではタイトル設計時に、
- 誰向けか
- どんな価値が得られるか
- どんな内容か
- どう伝えるか
を意識することが推奨されている。

## 池田OSでの変換

基本式:

誰向け
×
今困っていること
×
読後にできること
×
記事内の具体物

例:
弱い:
「Threads運用について考えたこと」

改善候補:
「Threadsは見られているのに予約が増えない美容師へ｜次に直す1か所を決める5段階診断」

## 禁止

- 実績の誇張
- 未達成の売上をタイトルに使う
- 「絶対」「必ず」等の保証
- 数字を入れるためだけの数字
- 本文にないメリット
- 読者不安を過度に煽る表現

## 評価

タイトルの良し悪しは主観で確定しない。

可能なら、
露出
→ 記事クリック
→ 無料部分到達
→ 購入導線
→ 購入

で比較する。

タイトル変更でPVだけ増えて購入が増えない場合、
本文・Evidence・無料/有料境界・価格・商品設計を切り分ける。
