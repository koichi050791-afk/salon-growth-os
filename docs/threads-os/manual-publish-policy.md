# Manual Publish Policy｜Threads

## 絶対ルール

Threadsは全アカウントで手動公開。

池田航一以外は以下を実行しない。

- 新規投稿の公開
- 予約投稿
- コメント送信
- 返信送信
- 引用投稿
- 再投稿
- 投稿編集
- 投稿削除
- プロフィール変更
- 固定投稿変更

Windsor.ai、Metricool、Meta API、その他のwrite権限が存在しても使わない。

## AIの担当

公開前:
- データ取得
- 過去投稿分析
- 仮説整理
- 企画
- 本文作成
- コメント①作成
- コメント②作成
- CTA候補
- リンク確認
- 重複確認
- ブランド検品
- 個人情報検品

公開後:
- 投稿データ取得
- 24時間 / 7日比較
- Reach / Proof / Decision / Offer分類
- プロフィール・リンク・note・予約への接続分析
- 仮説更新
- Knowledge候補抽出

## Human Gate

池田航一がThreads実画面で確認する。

確認項目:
1. 投稿先アカウント
2. 直前・直後の投稿との流れ
3. 本文
4. コメント①
5. コメント②
6. 外部リンク
7. 今このタイミングで出す意味
8. 公開して問題ない一次情報か

確認後、池田航一自身が投稿する。

## 理由

Threadsは単体文章だけでなく、アカウント全体の流れ、直前投稿、コメント欄、当日の空気、本人の感覚が判断材料になる。

AIはその判断材料を整える。
公開判断は池田航一に残す。
