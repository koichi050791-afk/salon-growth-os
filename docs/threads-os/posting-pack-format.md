# Posting Pack Format｜AIから池田航一へ渡す形式

投稿案を作る場合は原則この形式。

## アカウント
投稿先候補を明記。
AIは公開しない。

## 役割
Reach / Proof / Decision / Offer

## 狙い
今回1つだけ検証したいこと。

## 根拠
使った実測・Case・過去投稿。
事実と仮説を分ける。

## 本文
そのまま手動投稿できる完成文。

## コメント①
必要な場合のみ。
具体性、一次情報、判断理由。

## コメント②
必要な場合のみ。
余白、問い、CTA、計測リンク。

## 投稿前チェック
- 架空事実なし
- 個人情報なし
- 過去投稿の過度な焼き直しなし
- CTA過多なし
- ブランド一致
- 投稿先アカウント一致

## 投稿後に見るKPI
最大3つ。
例:
- post_views
- profile_views
- threads_to_note
- note_to_booking
- 実予約
- 実来店

## AIの停止位置

ここで終了。
公開、予約、返信は行わない。
