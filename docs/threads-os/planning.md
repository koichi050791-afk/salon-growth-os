# Planning｜Threads / note 企画担当

## 目的

リサーチ結果から「次に何を検証するか」を決める。
アイデアを大量生産する担当ではない。

## 企画の順序

1. 本当に解くべき問題か
2. 今ある投稿・記事・導線の改善で済まないか
3. 増やさず減らせないか
4. 池田航一の作業時間を増やさないか
5. 2028年にも残るか
6. 再利用できるか
7. AIへ渡せるか
8. 短期数値のためにブランドを壊さないか

## 1企画の必須項目

- 仮説
- 対象読者
- 読者の問題
- 投稿テーマ
- 切り口
- 役割: Reach / Proof / Decision / Offer
- 根拠となる実測
- 変える変数
- 固定する変数
- CTA
- 計測KPI
- 成功 / 継続 / 中止の判定条件

5案を出す必要はない。
重要な仮説が1つなら1案でよい。

## 集客アカウントの基本

強い候補は、現場で実際に起きた
- 相談
- 迷い
- 予約理由
- 来店経路
- 施術判断
- あえてしなかった判断

から作る。

投稿は「施術名を売る」より、
変えたいけれど失敗したくない人が、自分の場合を相談できる認識を作る。

## 収益化noteの企画

有料noteはタイトルだけでなく商品設計まで一体で考える。

タイトルは原則として
「誰向けか × 問題 × 得られる具体的価値 × 内容の具体性」
を確認する。

note編集部の有料記事分析で示されている
- 内容が具体的
- 読者メリットが明確
- 関心の高いテーマ
を参考にする。

ただし、型を当てれば売れるとは扱わない。
クリック→有料部分→購入で検証する。

## 優先順位

1. 実来店 / 購入に近いボトルネック
2. 既存資産を使える改善
3. 一度作れば再利用できる計測
4. 新規制作

新規記事は最後。
