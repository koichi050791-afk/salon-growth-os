# Ikeda Personal Office Retention Policy v1

更新: 2026-08-25

## 目的

池田航一のAI環境・情報環境を「大企業型」ではなく「個人事務所型」に保つ。

AI、プロジェクト、GPT、Skill、Automation、チャット、資料、開発機能は、作れるから残すのではなく、現在の2つの収益エンジンに継続的に価値を返すものだけ残す。

1. 本業: 9:00〜18:00と家族時間を守りながら月間技術売上130万円を持続的・安定的に達成する
2. 第二収益: 20年以上の美容師経験・判断・学び・AI活用を知的資産へ変換し、労働時間に比例しない収入を育てる

## 原則

- 現在使っていないものは「いつか使うかも」だけで維持しない
- 過去の肩書き・職責を現在のOSへ持ち込まない
- 同じ役割のProject / GPT / Skill / Agent / Automationを重複させない
- 情報を残すための仕組みより、必要な時に見つかる最小構造を優先する
- 完了した一時チャットは、再利用価値が正本へ移ったら削除候補とする
- Agent / Automation / Project / Chat数を成果KPIにしない
- 追加より統合、統合より削除を先に検討する

## 現在のHuman Core

池田本人が保持するもの:
- 顧客との会話
- 髪を見て触ること
- 違和感の検知
- 専門判断
- 価値判断
- ブランド・価格・顧客対応・公開・本番等の重要承認

AIへ渡すもの:
- 探索
- 比較
- 整理
- 要約
- 批評
- 変換
- 集計
- 重複除去
- 候補抽出

## ChatGPT Projects

目標は最大2つの常用Project。

### KEEP 1: Salon & Customer
含める:
- 130万円安定達成
- 日報 / 売上観察
- 顧客体験 / 再来 / 次回予約
- 施術ケース
- Decision / Not Chosen / Next Observation / Outcome
- 三田店・地域での現在の集客判断

### KEEP 2: Intellectual Asset & Second Engine
含める:
- note / Substack / Threads / Instagram等への変換
- 有料コンテンツ
- 第二収益
- 美容師経験の知的資産化
- 必要時の外部リサーチ

### DELETE / MERGE候補
- 旧「事業推進」専用Project
- 店舗横断改善Project
- 西宮北口店 / 逆瀬川店の改善Project
- AI会社の部署設計専用Project
- Agent Registry / Work Graph / Approval Queue等の設計専用Project
- 媒体ごとに分離しただけのProject
- 同じ施術ケースを別DBとして保持する重複Project
- 完了した調査だけのProject

## Custom GPTs

原則: 常用は最大1つ。

### KEEP
施術判断・ケース資産化系のGPTを、短い現場入力をDecision Captureへ整える単機能ツールとしてのみ残す。

### DELETE候補
- 池田AI編集部｜美容師コンテンツ制作室
  - 通常ChatGPTで代替可能
  - 知識ファイルとProject指示の重複が大きい
- AI会社 / CEO室 / 部署別AI社員など、組織を模しただけのGPTが作成済みなら削除
- リサーチ、SEO、文章、分析など、通常ChatGPTのon-demand capabilityで代替できる単機能GPT

## Skills

常設Skillは「実際に繰り返し使われ、説明の繰り返しを明確に減らす」ものだけ。

Skill化しないもの:
- 一回限りの調査
- 一回限りの記事
- 媒体別文章生成だけ
- SEOだけ
- 一般的なリサーチ
- 一般的な要約
- AI会社管理のためだけの監査

新Skillは、3〜4週間の実使用で反復負荷が確認された後にのみ追加する。

## Automations

原則: 日常で継続価値があり、池田の認知負荷を下げるものだけ有効化する。

KEEP:
- Morning Secretary Brief

STOP:
- Codex効率改善追跡
- Global Industry Radar
- Weekly Secretary Review
- Daily Secretary Close
- 三田競合発信チェック
- コンテンツ資産会議
- 集客マーケティング速報

必要になった情報は、その時点でon-demandに調査する。

## 旧「事業推進」業務

2026年7月以降の現職務には持ち込まない。

DELETE / ARCHIVE対象:
- 全店売上・生産性改善の横断管理
- 西宮北口店 / 逆瀬川店のHPB改善
- 店舗別GBP改善の横断担当
- 全店SNS素材回収・管理
- 幹部会議 / 全体会議向け事業推進資料
- 社内AI導入推進
- 店舗改善レポート
- 旧DX提案
- 旧「美容室向けAI事業推進OS」構想
- 他店舗の月次媒体PDFをPersonal Officeの常用資料として保持すること

歴史として必要な会社正式記録がある場合は会社側の正本に任せ、池田個人のPersonal Officeでは二重保管しない。

## Chats

KEEPするチャット:
- 現在進行中で次の実行が残っている
- REALな施術一次情報があり、まだ正本へ移していない
- 130万円 / 第二収益の現在判断に直接使う
- 他に正本が存在せず、再利用価値が明確

DELETEするチャット:
- URLを一度要約しただけ
- 結論をすでに別Project / GitHub / note戦略へ反映済み
- 旧事業推進、全店改善、西宮北口、逆瀬川の業務チャット
- AI会社、部署、AI社員、Agent設計の検討が結論済み
- Claude等へ送る指示文を作り終えただけ
- 単発の投稿文を作成して公開済み
- 同じテーマの重複チャット
- 完了したトラブルシュート
- 「将来使うかも」以外に保持理由がない

## File retention

KEEP:
- 現在のプロフィール / ブランド方針
- 施術・カウンセリング判断基準
- REAL Case / Decisionの正本
- 現在の料金・予約・店舗情報
- 130万円プロジェクトの現在正本
- 第二収益の現在正本

DELETE候補:
- md / txt等の内容重複ファイル
- 旧GPT用統合知識ファイル
- 旧事業推進資料
- 旧店舗横断改善資料
- 旧AI会社ロードマップ
- 使わない生成画像・一時資料

## Plugin / external apps

Keep candidates:
- Gmail / Google Calendar / Google Contacts
- Google Drive
- Airtable
- GitHub / Vercel（Personal OS開発を行う時だけ）
- Canva（実際の発信制作時だけ）
- Notion（正本として現用している範囲だけ）

Remove candidates when installed but unused:
- Zoom
- Coursera
- Genspark Slides
- Lovable（My Hair OS開発を再開するまで）
- Remotion

外部Appの削除は接続・権限を伴うため、対象Appを明示して個別実行する。

## 新規追加Gate

Project / GPT / Skill / Automation / Agent / Dashboardを新しく追加するには、以下を全て満たす。

1. 現実に繰り返す仕事がある
2. 現在の2 Project / 通常ChatGPTで代替できない
3. 池田の時間または判断負荷を明確に減らす
4. 本業130万円または第二収益に接続する
5. 維持コストが利益より小さい
6. 3〜4週間後に不要なら消せる

1つでも満たさなければ作らない。

## 最終形

池田航一
+ ChatGPT
+ Salon & Customer Project
+ Intellectual Asset & Second Engine Project
+ Decision Capture用GPT 1つ
+ 必要時だけ呼ぶ外部Tool

これをPersonal Officeの標準形とする。
