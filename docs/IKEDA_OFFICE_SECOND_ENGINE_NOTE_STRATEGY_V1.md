# IKEDA OFFICE Second Engine / Industry note Strategy v1

更新: 2026-08-25

## 1. 最上位テーマ

**美容師の経験を、働く資産に変える。**

「美容師特化型OS」「AI×美容師」「美容師経営」「マーケティング」は独立テーマとして並列に扱わず、この上位テーマの下に統合する。

OSを作ること、AIを使うこと、noteを書くこと自体を目的にしない。

最上位目的は、現場美容師として20年以上積み重ねてきた経験・判断・失敗・検証を、その日の仕事だけで消費せず、次の施術・顧客体験・発信・商品へ再利用できる知的資産へ変えること。

長期的には以下の2軸を作る。

1. 130万円の技術売上を安定させる本業
2. 労働時間に比例しない第二収益エンジン

第二収益エンジンは完全な不労所得を意味しない。

**一度作った知的資産が、池田本人が施術していない時間にも繰り返し価値を生む状態**を目指す。

## 2. 第二エンジンの基本構造

現場 → 経験 → 記録 → 検証 → 判断原理 → 知的資産 → 発信 → 商品 → 収益

現場美容師を辞めて別事業を作るのではない。
**現場そのものを第二エンジンのR&Dとする。**

## 3. AIの役割

AIへ任せる:
探索 / 整理 / 比較 / 過去ケース検索 / 共通点・相違点抽出 / 反例探索 / 次回確認候補 / 発信候補 / 既存記事更新候補 / 商品候補 / 監査

AIへ任せない:
顧客を見る / 髪に触れる / 話を聞く / 違和感を感じる / 原因仮説を採用する / 施術方針を決める / 最終判断する

基本思想:

**池田にしかできない現場観察・違和感・最終判断へ時間を集中し、調査・比較・整理・変換・監査はAIへ渡す。**

## 4. noteの役割

noteは記事数を増やす場所ではない。

- 知的資産の公開
- 市場テスト
- 検索資産
- 信頼形成
- 商品への入口

新記事を書く前に、既存記事への追加・更新・統合で済まないかを先に確認する。

## 5. 無料 / 有料

無料は問題提起、一次事例、考え方、検証途中の仮説、失敗・修正まで十分に渡す。
無料を不完全にして有料へ誘導しない。

有料は「分かった」から「自分の現場でもできる」まで持っていく。

- 手順
- 判断基準
- 記録方法
- 比較方法
- チェックリスト
- テンプレート
- 失敗条件
- 導入方法
- AIワークフロー

## 6. 商品価値の5層

1. Feature｜何を渡すか
2. Surface Problem｜読者が使っている悩みの言葉
3. Desired Outcome｜解決すると何が変わるか
4. Avoided Loss｜何を失いたくないか
5. Core Value｜最終的な仕事・生活・判断の変化

Featureから売らない。Surface ProblemからCore Valueまで階段を作る。

## 7. Product Validation Gates v2

### Gate 0｜Problem
実在する問題か。読者自身の言葉か。複数の独立した観測があるか。

### Gate 0.5｜Desire / Value
何を得たいか、何を避けたいか、現状維持のコストは何か、商品機能と欲しい未来がつながっているかを確認する。
5層が曖昧なら有料化しない。

### Gate 1｜Free Asset
無料記事への具体的需要を観測する。
強いシグナルは「どうやる」「テンプレが欲しい」「自分にも使えるか」「どこから始めるか」。

### Gate 2｜Paid Asset
最重要Evidenceは購入。
売れない時は本文を増やす前に、入口 / 問題認識 / 欲しい未来 / 価値理解 / 信頼 / 価格 / タイミング / 利用イメージのどこで止まったか診断する。

### Gate 2.5｜Use / Outcome
購入は完成証明ではない。実利用、詰まり、個別説明の必要性、行動変化、Outcomeを確認する。

### Gate 3｜Reusable Tool
繰り返し使われた部分だけテンプレート / Starter Kit化する。

### Gate 4｜Playbook
複数人・複数ケースで成立条件、不成立条件、例外が分かったものだけ体系化する。

### Gate 5｜System / Product
勝った複数資産が反復行動として接続し、ソフトウェア化で明確に価値が増える場合だけ検討する。

## 8. 現在地｜2026-08-25

現在は **Gate 0〜1：Problem / Desire / Free Asset Validation**。

大型商品、Starter Kit、Playbook、講座、コミュニティ、SaaS、月額サービスを先に作らない。

## 9. 需要検証3テーマ

### Theme A｜経験をどう残せば、次に使えるのか
主資産: IP-004 / IP-010 / IP-006
Core Value: **働くほど、自分の専門性と知的資産が増えていく。**

### Theme B｜AIをどう使えば、経験を再利用できるのか
主資産: IP-003 / IP-013 / IP-001
Core Value: **AIによって仕事を増やすのではなく、人にしかできない判断へ時間を戻す。**

### Theme C｜現場の判断を、どう発信・商品へ変えるのか
主資産: IP-002 / IP-029 / IP-004
Core Value: **美容師として働くこと自体が、次の収益資産を生む。**

優先順位は A → B → C。

## 10. 記事を書く前の10問

1. 誰のどんな場面の問題か
2. 読者が実際に使う言葉は何か
3. 放置すると何を失うか
4. 解決すると何が変わるか
5. 商品が提供する機能は何か
6. なぜその機能で結果へ近づくのか
7. 池田が語る根拠は何か
8. 無料でどこまで渡すか
9. 有料で何を実行可能にするか
10. 購入後に何を観測すれば価値を検証できるか

この10項目が決まってから本文を書く。

## 11. 売れない時の禁止事項

- 理由を確認せず情報量を増やす
- 時間をかけた = 良い商品、と判断する
- PV / スキだけで需要証明する
- 無料記事を不完全にして有料へ誘導する
- 恐怖・損失を誇張する
- 未検証Outcomeを実績として売る
- AI生成物の量を商品価値とする
- 他者の販売実績を池田の再現可能性とみなす

## 12. 販売原則

**商品を売るとは、価値を誇張することではない。読者が見落としている問題・コスト・可能性を、理解できる順番で見えるようにすること。**

商品品質は、

**購入 → 利用 → 行動変化 → Outcome**

まで見て判断する。
